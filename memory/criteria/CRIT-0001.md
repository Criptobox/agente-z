## Contexto
Identificado por el usuario en la sesión de diseño del sistema (2026-08-11).

## Cómo se aplica
- `code` y `research` deben usar `read_project_file` para traer el archivo completo cuando lo necesitan, no recortar con grep.
- Cuando reportan findings, citan `archivo:línea` pero el contexto visual es el archivo completo.
- Los handoffs referencian archivos por path, no por fragmento.

## Cuándo retirar
Si el usuario cambia a un workflow basado en diffs (review-style), este criterio se puede retirar.
